# 历史有界化验收记录

日期：2026-10-28。对应对 `4f098e57` 的第一优先级改进；设计、配置和存储协议见 [历史保留策略](history-retention.md)。

## 万次完整链路实验

命令：`python benchmarks/retention.py --out results/retention-2026-10-28.json`。

四个 Context 共执行 **10,000 个真实 Python 叶子工具任务**，内容为读文件、文本搜索和 JSON 解析；每个 Run 最多 32 个任务，共创建并关闭 **320 个 Run**。经过 FocusToolAdapter、执行前准入回调、Go stdio 服务、每条 WAL 变更 fsync、消费者 checkpoint fsync 和顺序 ack。并发上限 8、全局任务额度 128、每 Run 额度 16、活动 Run 上限 8、WAL 段目标 256 KiB。

| 已完成任务 | 已关闭 Run | GC 后 Go 堆 MiB | 近期缓存任务／事件数 | 自动压缩次数 |
|---:|---:|---:|---:|---:|
| 1,000 | 32 | 1.297 | 76 | 9 |
| 2,000 | 64 | 1.302 | 41 | 19 |
| 3,000 | 96 | 1.288 | 5 | 29 |
| 4,000 | 128 | 1.424 | 81 | 38 |
| 5,000 | 160 | 1.388 | 47 | 48 |
| 6,000 | 192 | 1.370 | 13 | 58 |
| 7,000 | 224 | 1.510 | 86 | 67 |
| 8,000 | 256 | 1.455 | 53 | 77 |
| 9,000 | 288 | 1.435 | 18 | 87 |
| 10,000 | 320 | 1.528 | 90 | 96 |

以上每次采样中，活动任务、待消费事件、活动 Run、队列 owner 数均为 **0**；Python 工具注册表、邮箱和活动订阅也均为 **0**。近期缓存随当前段占用变化，没有保存全量历史身份索引。采样时 WAL 最大 216,551 字节，低于 256 KiB 目标。96 次自动压缩后另做一次显式压缩和重启，原任务重提返回原终态与原完成时间，游标继续读取下一条原始事实；重启后缓存和活动索引均为 0，Go 堆 **775,304 字节（0.739 MiB）**。

全程约 **491.86 秒**，包括采样和末尾恢复检查。实验早期同时执行了本仓其他验证，故该时间仅描述本次验收运行，不作为独立吞吐／延迟基准。记录的 10,000 条 sequence 和 `(Context, Run, job_id)` 均唯一、终态均为 completed。数据记录每次完成及消费时间，没有把工具执行和 Run 消费混为一个事实。

磁盘 canonical 记录正文合计 **12,269,729 字节（11.70 MiB）**，不含文件系统目录、分配单元及其他元数据。旧身份、结果和消费水位继续保存在磁盘；本轮没有实现磁盘 TTL。堆数值仍有上升和波动，本实验验证的是活动索引和近期历史受明确策略约束，并不证明堆/RSS 严格恒定、操作系统缓存有界、无限时长稳定或生产 Patrol 就绪。

该入口保留的 1,024 次持续提交测试使用**默认 8 MiB**段目标，约 59.86 秒内 WAL 从 0.34 增至 2.50 MiB，尚未达到轮换阈值，因此近期缓存从 144 增至 1,040 个任务／事件，GC 后堆从 1.078 增至 2.638 MiB；它没有承诺“关闭即清空近期缓存”。16 个停止消费结果一直保留在活动事件索引，未阻塞其他 Context；交给 archive 后活动事件清空，近期缓存仍在段内。前述 256 KiB 万次实验专门覆盖持续多轮压缩，分别报告这些数值，避免把低于阈值的增长误说成不存在。

## 正确性回归

- 17 条各 512 KiB 的合法结果按条数和字节分页；压缩、断连重启后续读，其他 Context 仍可使用共享连接。
- 游标绑定 owner 和固定 high-water；已关闭但仍有执行收尾的 Run 后续产生新事实，旧游标不会混入它们，新查询可读到。
- 历史 ID 重提返回既有状态，参数冲突拒绝；已 ack 并移出活动索引的旧结果仍能绑定后继 Python 参数，保持大整数精度。
- unknown 经 ack、关闭、压缩和重启仍占用额度、隔离冲突资源，不自动重放。
- 部分磁盘索引更新、sealed 后尚未创建新段及新段尾帧不完整均能回放恢复；存储失败后分页先 fail closed，恢复后不重复事实。
- 超过旧 128 MiB 整体上限的 **129 MiB 以上**合法日志可流式恢复并压缩。较低恢复配额会联合计算任务和未确认结果并拒绝超额启动。
- 关闭句柄回收后迟到帧不会重建邮箱；历史终态重提／reconcile 不残留授权注册。

完整 Go 测试、go vet、**21 项 Python 回归／集成测试**和 Demo 通过，见 [完整输出](../results/retention-verification-2026-10-28.json)。真实 Focus 固定源码 `340bf2b8` 的允许执行、权限撤销、租约释放三例再次通过，见 [本轮联调记录](../results/focus-retention-integration-2026-10-28.json)；该联调仍使用本地确定性决策和隔离 PostgreSQL，范围见 [接入边界](../integration/focus/README.md)。
